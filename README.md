# استودیو آرکا — دموی وب‌سایت

نسخهٔ نمایشی (دمو) وب‌سایت یک استودیوی طراحی و اجرای **کابینت آشپزخانه، کمد دیواری و کلوزت روم**.
این سایت کاملاً **ثابت (static)** است: بدون بیلد، بدون سرور و بدون وابستگی به هیچ فریمورکی؛ هر فایل HTML را که باز کنید در مرورگر اجرا می‌شود و برای انتشار روی **GitHub Pages** آماده است.

## صفحه‌ها

| فایل | صفحه |
| --- | --- |
| `index.html` | صفحهٔ اصلی |
| `services.html` | خدمات ما |
| `cabinets.html` | انواع کابینت آشپزخانه |
| `closets.html` | کمد دیواری و کلوزت روم |
| `portfolio.html` | نمونه‌کارها (با فیلتر دسته‌بندی) |
| `blog.html` | مجله |
| `article.html` | نمونهٔ صفحهٔ مقاله |
| `contact.html` | تماس با ما (فرم دمو) |
| `design-system.html` | سیستم طراحی: پالت، تایپوگرافی و اجزای رابط |

## ساختار پوشه‌ها

```
├── index.html            # صفحه‌های سایت
├── assets/
│   ├── css/site.css      # کل استایل‌ها (Design System)
│   ├── js/site.js        # منوی موبایل، فیلتر نمونه‌کارها، فرم دمو
│   └── img/*.webp        # تصاویر بهینه‌شده (وب‌پی)
├── design-frames/        # فایل‌های اولیهٔ طراحی (فقط برای مرجع)
└── README.md
```

## انتشار روی GitHub Pages

1. مخزن جدیدی در GitHub بسازید (مثلاً `araka-studio-demo`) و فایل‌ها را push کنید:

   ```bash
   git init
   git add .
   git commit -m "اولین نسخهٔ دموی سایت استودیو آرکا"
   git branch -M main
   git remote add origin https://github.com/<نام-کاربری>/araka-studio-demo.git
   git push -u origin main
   ```

2. در صفحهٔ مخزن، به **Settings → Pages** بروید.
3. در بخش **Build and deployment** گزینهٔ Source را روی **Deploy from a branch** بگذارید.
4. Branch را `main` و پوشه را `/ (root)` انتخاب کنید و Save بزنید.
5. چند دقیقه بعد، لینک سایت شما در همان صفحه نمایش داده می‌شود:
   `https://<نام-کاربری>.github.io/araka-studio-demo/`

> نکته: چون فایل‌ها با پسوند عادی HTML هستند، نیازی به فایل `.nojekyll` هم نیست؛ ولی برای جلوگیری از هر پردازش جانبی، همان‌طور که می‌بینید یک فایل `.nojekyll` خالی کنار پروژه گذاشته شده است.

### مشاهدهٔ محلی

کافی است روی هر کدام از فایل‌های HTML دوبار کلیک کنید، یا یک سرور کوچک محلی اجرا کنید:

```bash
python -m http.server 8000
# سپس http://127.0.0.1:8000 را باز کنید
```

## نکات مهم دربارهٔ نسخهٔ دمو

- **اطلاعات تماس، آدرس و پروژه‌ها نمونه‌اند.** پیش از ارسال برای مشتری نهایی، شمارهٔ تلفن، نشانی و نام استودیو را عوض کنید. نام برند در همهٔ صفحه‌ها یک‌جا (هدر و فوتر) تکرار شده و به‌سادگی قابل تغییر است.
- **فرم تماس دمو است** و داده‌ای ارسال نمی‌کند؛ پس از تأیید نهایی می‌توان آن را به سرویس فرم (مثلاً Formspree یا ابزار مشابه) وصل کرد.
- **تصاویر** از پوشهٔ `assets/img` بارگذاری می‌شوند و بهینه‌شده‌اند (مجموعاً حدود ۴۳۰ کیلوبایت).
- فونت‌ها (Vazirmatn و Estedad) از Google Fonts بارگذاری می‌شوند و برای نمایش نیاز به اینترنت دارند.
